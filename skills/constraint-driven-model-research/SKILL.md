# 约束驱动竞赛建模

通过实际实验建立可复现、符合约束且能在评测环境运行的模型。工作循环为：**理解任务 → 建立验证与基线 → 小批探索 → 根据结果调整搜索 → 保存模型确认 → 交付**。

评价指标、标签、数据许可、资源上限和研究目标按当前任务确定。读取已有配置与日志，沿用有效证据和剩余预算。

## 1. 核对规则、数据与提交接口

- 先读赛题、规则、提交指南、数据字典、官方样例和评价代码，确认训练与推理各自能取得什么数据、如何输出、受哪些资源限制。
- 按 [protocol.md](references/protocol.md) 建立本轮设置：主指标、保护指标、数据边界、验证切分、比较条件、预算和产物位置。记录规则原文、实现与有效澄清之间的冲突。
- 检查字段可见时点、标签构造、重复/缺失样本和数据覆盖。时序任务先画出特征、决策和标签结束的时间关系，再写切分代码。
- 目标或口径存在关键缺项时集中询问；同时推进材料检查、数据审计和已明确的基线工作。普通本地实验在授权内自主执行；明确要求先做计划时不启动训练。

## 2. 建立真实可复现的参照

从官方基线走通数据、训练、保存、重新加载、推理和评价；没有官方实现时，建立适配任务的简单参照。首次完整运行同时记录耗时、峰值内存和输入输出格式，用它估算后续实验规模。已有可信权重时可先重放核对，是否重训取决于任务要求及产物可信度。

比较日期、有效样本、成本、约束和评价实现固定后，再搜索新方案。保留原始数据和既有结果，新实验另建目录。基线值不一致时先定位数据、配置、权重和实现差异。

在大量搜索前确定验证与保留区间。时序任务按时间向前训练，训练标签须在评价期前成熟；预处理、监督表示和下游模块遵循相同边界。验证期反复用于选择后属于开发数据；剩余未观察区间用于最终检查。具体切分与泄漏检查见 [protocol.md](references/protocol.md)。

## 3. 用结果决定下一批实验

按 [search.md](references/search.md) 小批推进：

1. 根据基线误差和数据特点提出少量假设，记录父模型、改动、比较方式、消耗和晋级/停止条件。
2. 实际训练并评价；仅在配置和依赖允许时复用权重或预测。计划条目与已完成实验分别记录。
3. 读取结果后决定缩小步长、扩大范围、增加训练资源、补齐验证折、换机制或停止分支。
4. 晋级者进入完整验证；始终为最终拟合、保存模型复跑和交付保留预算。

首批可以探索较宽的机制范围，后续按证据分配资源；不要一次列满参数网格后机械跑完。低保真初筛与正式结果分开，避免过早剪掉有慢收敛迹象的神经网络。不能因为单个折或末位小数占优就消耗大量预算。

## 4. 分清提升来自信息、表示还是模型

- 逐步比较原始字段、清洗/变换、手工特征、学习表示、学习器、监督目标与训练窗口。用同输入换模型、同模型换输入等对照定位增量。
- 根据任务选择线性、树模型或神经网络等可行候选；文献提供假设，任务内实测决定去留。检查复杂结构是否增加了已有模型缺少的能力。
- 对有效模型既可做有限修正，也可重训表示或整体结构；搜索范围服从当前任务。收益停滞时回到误差、数据和目标，避免只围绕融合系数微调。
- 实际解冻时核对可训练参数、梯度与权重变化，重建依赖它的特征/表示和下游模块。上游改变后使旧缓存失效，明确此次真正重训了哪些部分。

## 5. 多目标任务沿实际决策链诊断

预测指标与业务/组合指标分开记录。股票任务检查 **分数/排名 → 目标持仓 → 实际成交与费用 → 主动收益与跟踪误差**；RankIC 与组合 Information Ratio 不能互相替代。高 RankIC、低 IR 时，检查头部/边界、同分处理、分数幅度、风险与换手。不能靠改成本、换困难区间或放宽约束制造达标。

采用本轮明确的多目标选择规则并保留有价值的非支配候选；目标改变时复审旧剪枝理由。“再提高多少”始终相对本轮固定起点。外部反馈用于诊断和选择时计入开发过程；汇总榜单不足以识别具体持仓事件，也不能保证下一次成绩上升。

## 6. 按资源和规则确认，再交付

按 [validation.md](references/validation.md) 重新加载保存模型，从原始允许输入运行真实推理入口并重算正式指标。分别说明确认覆盖抽样日期、部分折还是完整区间，以及实际做了训练、回放、回测还是接口检查。

加载/推理耗时、峰值内存、依赖和输出格式都是候选条件，从基线阶段就测量。加速按瓶颈改动，核对输出语义和实际收益；验证范围与改动风险匹配，避免重复大规模验证。

规则涉及评测期统计、历史标签或状态更新时，以当前比赛文档和有效澄清确定边界，验证时点、总回看依赖与状态行为；其他比赛的许可不构成本赛授权。需要并行代理且已有授权时，明确分支、文件归属、预算和总资源。

持续保存全部实验配置、结果和失败/剪枝原因。交付选定权重、训练/推理代码、完整实验表、复现命令与确认范围；预算耗尽时报告最好结果和差距。外部提交依当前授权执行。用户说“继续”时接续有效记录和剩余预算。
