# 自适应搜索与诊断

在基线已经运行、准备安排下一批实验时阅读。按当前证据选动作，不要求依次遍历所有模型或方法。

## 从基线误差提出首批假设

先看误差在时间、实体/行业、目标分位、缺失模式及市场状态上的分布，并检查简单特征与目标的关系。区分数据问题、缺少信息、表示受限、目标错配和评价链问题。

首批用少量对照确定值得投入的方向。例如：

- 同一模型，增加一组合法输入或改变预处理，检查信息增量。
- 同一输入，比较简单线性、树模型与适配任务的神经网络，检查非线性或交互价值。
- 固定结构，改变损失、标签变换或训练窗口，检查监督和时间适应性。

只选与诊断相符且资源可承受的探针。具体候选来自数据特点、规则、已有结果与相关文献；查阅新方法时核对原始论文/实现及其适用前提。

## 一批结束后再决定下一批

每批说明参照、假设、改动、初筛折/训练资源、晋级条件、停止条件及预计消耗。用实际结果更新计划：

| 观察 | 下一步 |
| --- | --- |
| 多折同向改善且仍有趋势 | 补齐验证，局部扩展范围或增加训练资源 |
| 改善只在单折或接近运行波动 | 用配对折/种子复核，或降低优先级 |
| 强度过大导致退化、较小值有效 | 缩小步长，检查保持项或使用范围 |
| 多轮系数微调收益停滞 | 转向输入、表示、监督目标或信息交互 |
| 神经网络早期弱但学习曲线仍改善 | 给一次有上限的延长训练机会 |
| 无增量且消耗高，或护栏明确失败 | 停止当前配置，记录证据；必要时改机制后新建候选 |
| 超出规则或资源可行域 | 提前拒绝，记录原因 |

不要先生成完整大网格再跑完。可以使用随机、贝叶斯或多保真搜索，但搜索器的范围、指标和晋级资源须随证据调整；不要让其优化了错误的本地代理目标。

低保真初筛可用部分时间折、较少训练轮次或较小样本；各候选应尽量共享初筛条件。筛选年占优不代表全期通过。区分“当前配置未通过”和“整个机制无效”，同时遵守固定护栏。

## 分离信息、表示与学习器的贡献

分别记录原始输入、手工特征、学习表示、模型、监督目标和窗口的变化。联合改进可以探索，关键候选随后用消融或匹配对照判断贡献及必要复杂度。

神经网络选择应回答具体问题：需要时间依赖、跨实体交互、条件门控、排序目标还是更有效的压缩？与输入和训练预算匹配的基线比较，避免把参数增加当成能力增加。

已有可靠模型时，可测试从零增量起步的小修正，并用收缩、正则或保持项控制偏离；证据支持后扩大自由度。若任务要求底层重构，实际解冻表示或重训模型，核对可训练参数、梯度和权重变化，重建下游表示及缓存。融合微调、局部重训与整体重训分别记账。

训练目标或结构变化通常需要重训；纯输出后处理可能只需重推理。复用前核对训练折、数据、特征顺序、预处理、上游权重和目标是否兼容。

## 多指标与组合指标的分歧

按正式评分及保护指标选择候选，保留当前目标下的非支配集合。指标缺失或口径不同的候选不能作完整支配比较。平均提升之外，还看各时间段的退化、实际误差与额外成本。

股票任务沿分数/排名、目标持仓、成交、费用、主动收益和跟踪误差逐段比较。全截面 RankIC 改善可能来自不影响持仓的区域；少数边界换位、同分处理、幅度、风险或换手也可能使组合指标退化。

可按诊断测试收益幅度/风险/成本目标、稳定性约束或限制信号作用区域。限制头部改动可能保护可靠持仓，但名单相同不保证不同优化器下的权重、成交与费用相同。用实际评价链核查。

只有榜单汇总值时，把原因记为待验证解释，不指定某只股票或风险事件为根因。本地小优势也不能保证迁移到未知设置。

## 目标更新与有限外部反馈

评分或保护门槛变化后，按旧剪枝理由复审候选，区分可复用产物、需要补折和需要重训的版本；保留当时判定，不改写历史记录。

外部机会只在授权内使用。选择有机制依据、差异足够明显且本地确认范围清楚的版本，保存不可变包与实际回传结果。公榜反复指导选择会增加选择偏差，不能保证逐次上升；避免用微小差分反复消耗机会。

## 特殊能力先验证边界，再验证增量

若规则允许使用推理窗口内已实现的历史结果，先推导可用标签的最新时点、发布延迟、上游依赖和状态限制。明确哪些参数离线固定、哪些量仅由当次输入计算，不能仅凭“没有调用 fit”判定合规。

合规后从最小可辨别原型开始，再分别测试窗口、收缩、时间权重、表示、目标和作用区域。把该模块与长期模型作配对对照，检验增量与稳定性；不预设局部统计能替代离线模型。
